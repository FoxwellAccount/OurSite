# 🦊 Foxwell Games - Official Website

Welcome to the official repository for the **Foxwell Collective Interactive** (publicly known as Foxwell Games) indie game development studio website! 🎮✨

## ✨ Features

* **Minimalist Developer UI:** 💻 A clean, highly fluid interface inspired by GitHub's dark mode, utilizing an absolute pitch-black background for maximum contrast and performance.
* **Dynamic Customization:** 🎨 Users can select a custom theme color from a full rainbow palette and toggle luminescence (glow effects) on the initial setup screen, instantly updating CSS variables across the site.
* **Interactive Architecture:** 📂 Smooth expandable accordion tabs for seamless navigation through Projects, Blogs, Curiosities, Settings, Legal Rights, and Contact forms.
* **Lore & Project Hub:** 🔍 Spoiler-free technical sheets and premises for our upcoming titles, including *Institute Of Everlight: Relics of the Golden Age*, *Foxwell Launcher (FL)*, and *Foxwell Systems (FS)*.
* **Terminal Navigation:** ⌨️ Integrated CMD-style interface in the header allowing users to navigate and expand tabs instantly via keyword inputs.

## 📁 File Structure

* `index.html`: Main HTML5 semantic structure, Setup and Terms splash screens, and interactive container elements.
* `style.css`: Advanced stylesheet containing dynamic CSS variables, fluid transition curves, and responsive design rules.
* `script.js`: Core scripting handling DOM manipulation, screen state transitions, theme updates, accordion math, CMD logic, and the mailto link generator.
* `*.png`: Official image assets for the studio logo and detailed blog galleries (*Fizzy Foxwell*, *Clarity Glasswell*, and *Walkie-Talkie Teaser*).

## 🚀 Deployment

This project is built using pure vanilla HTML, CSS, and JavaScript, requiring no external build tools or package managers. 🌐

To deploy via GitHub Pages:
1. Upload `index.html`, `style.css`, and `script.js` to the root of your repository.
2. Upload all properly named `.png` assets to the root directory.
3. Enable GitHub Pages in your repository settings targeting the main branch.
