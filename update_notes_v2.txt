System & UI Logic Improvements:
- CMD Terminal: Enhancing the command parsing and suggestion logic for a smoother user experience.
- Intelligent Accordion System Refinement: The expandable accordion system is already implemented, but we will be refining its behavior. Currently, main accordion tabs open, but after opening a main tab and then opening a nested tab inside it (especially if the nested tab is close to the lower edge of the main container), the main tab gets cut off and fails to adapt its size dynamically to the newly opened nested content. The only workaround currently is closing the main tab and reopening it, as if the main tab retains a fixed default height value and only recalculates layout height upon toggle. To resolve this, we will introduce a smart toggle and height calculation logic for nested tabs: opening a nested accordion will automatically close any other open nested tab within the same parent block and re-render the parent container's dynamic bounds. Main accordion tabs will remain independent.
